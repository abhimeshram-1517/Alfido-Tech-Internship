# Student Management System

A simple CRUD web application developed using Python Flask,
HTML, CSS, Bootstrap, and SQLite.

## Features

- Add student records
- View student records
- Edit student information
- Delete student records
- GET and POST form handling
- SQLite database integration
- Responsive Bootstrap interface

## Technologies Used

- Python
- Flask
- HTML5
- CSS3
- Bootstrap 5
- SQLite

## Installation

1. Clone this repository.

2. Open the project directory.

3. Create a virtual environment:

   python -m venv venv

4. Activate the environment on Windows:

   venv\Scripts\activate

5. Install dependencies:

   pip install -r requirements.txt

6. Run the application:

   python app.py

7. Open the following address in your browser:

   http://127.0.0.1:5000

The SQLite database and students table are created automatically.

## CRUD Operations

- Create: Add a student
- Read: View all students
- Update: Edit student details
- Delete: Remove a student

## Purpose

This project demonstrates Flask routing, template rendering,
form handling, database integration, and basic CRUD operations.
