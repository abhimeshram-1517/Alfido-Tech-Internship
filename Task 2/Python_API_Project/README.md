# Python API Data Fetcher and JSON Handler

## Objective

To learn how Python communicates with external APIs, retrieves data using the Requests library, parses JSON responses, searches records, and handles API errors.

## Technologies Used

* Python
* Requests Library
* REST API
* JSON
* Visual Studio Code

## API Used

JSONPlaceholder Users API:
https://jsonplaceholder.typicode.com/users

## Features

1. Fetches user information using HTTP GET requests.
2. Parses JSON responses into Python data structures.
3. Displays user details in the terminal.
4. Searches users by name, email, or city.
5. Handles HTTP errors, connection failures, and timeouts.
6. Validates user menu input.

## Installation

Install the required library using:

```bash
python -m pip install requests
```

## Execution

Run the following command in the VS Code terminal:

```bash
python api_data_fetcher.py
```
